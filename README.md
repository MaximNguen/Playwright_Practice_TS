# Playwright_Practice
Сложный фреймворк автоматизации тестирования UI сайта, который я тестировал вручную (Проект коммерческий)

Что тестируется?
- Выполняет сквозные тестирования (От входа в аккаунт до создания задач и тд)
- Тестирование системы авторизации
- Тестирования БД
- Тестирование UI
- Тестирование кликабельность кнопок и переход страниц
